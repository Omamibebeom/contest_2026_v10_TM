# 比賽操作｜顏色辨識／座標辨識

只保留正式比賽會用到的兩個功能。

**共用**

| 項目 | 內容 |
|------|------|
| 網線 | 樹莓派 `192.168.1.10`，手臂 `192.168.1.20`，埠 `5000` |
| 比賽指令 | `cd ~/Desktop/contest_2026_v10_TM` → `python3 main_contest.py --no-ui` |
| 啟動 | 等到 **「階段二: 可以按手臂了」** 再按手臂；比賽中不要關程式 |
| Script | 顏色 → `docs/tm-a-flow-v1.txt`；座標 → `docs/tm-b-flow-v1.txt` |

顏色名鐵則：`vision_profiles.json`、`PICK_ORDER`（以及若有改的 `IO_CODES`）三處一模一樣、全部小寫。

TMflow 變數管理員新增的變數會自動帶 `var_` 前綴；Script／IF 請用完整名稱（如 `var_color_code`）。

# 功能一：顏色辨識（a）

物件位置固定。夾起 → 舉到鏡頭前 → 問顏色 → 依代碼放置。

## 校正（賽前）

```text
python3 vision_tuner.py
```

1. 畫面左＝相機、右＝mask；調 H／S／V，讓 mask **幾乎只剩目標物是白的**  
2. 按 `s`，輸入顏色名存檔（**小寫**，如 `red`／`blue`／`green`）  
3. 按 `n` 換下一個顏色繼續調；全部存完按 `q` 離開  
4. 結果在 `vision_profiles.json`  

`IO_CODES` 預設已對應下面代碼表，**通常不用改**。

## 手臂要背的代碼（預設）

| `var_color_code` | 意思 |
|------------------|------|
| 1 | red |
| 2 | blue |
| 3 | green |
| 7 | 失敗 |

**手臂：** 變數管理員建 `a_raw`、`color_code`（實際為 `var_a_raw`、`var_color_code`）→ Script 貼 `tm-a-flow-v1.txt` → IF 依 `var_color_code` 去放置點。

## 當天操作

1. 開 `python3 main_contest.py --no-ui`，等到階段二  
2. 夾起物件 → 移到鏡頭前  
3. 跑 **a Script**（`A_REQ` → 收 `$A,數字` → `A_DONE`）  
4. 依 `var_color_code` 放置  
5. 下一件再跑一次 a Script  

**口訣：** 先校正顏色 → 當天要顏色跑 a → 看 `var_color_code`。

# 功能二：座標辨識（b）

隨機板。開機拍快照算座標；手臂問「下一件在哪」再去夾。

## 校正（賽前）

### 1）顏色（與 a 相同）

先用 `vision_tuner.py` 存好顏色（快照要辨得出物件顏色）。

### 2）像素 ↔ 手臂取樣

```text
python3 affine_sample_tool.py
```

1. 鏡頭下放置件，畫面十字對準目標  
2. `SPACE` 鎖定像素座標  
3. 手臂 Jog 到該點**正上方**，看教導器 X、Y  
4. 按 `c`，輸入手臂 X,Y  
5. 重複取點（建議四角＋中心，**至少 3 點、勿共線**）  
6. 按 `p` 印出清單，抄進 `affine_transform.py` 作答區 1 的 `PIXELS`／`ARMS`  
7. `u` 可刪上一點，`q` 離開（離開前也會再印一次）

### 3）寫轉換並驗算

1. 在 `affine_transform.py` 作答區 2 寫好 `fit()`（比賽常挖空）  
2. 執行：

```text
python3 affine_transform.py
```

3. 能印出六個參數（`X = …`、`Y = …`）＝校正成功  
4. **相機一動，取樣與抄點必須重做**

### 4）夾取順序

在 `main_contest.py` 頂端填 `PICK_ORDER`（小寫），例：

```text
PICK_ORDER = ["red", "blue", "green"]
```

→ 第 1、2、3 次 `GET` 依序給這三色；同色兩件就寫兩次。

**手臂：** 變數管理員建 `b_raw`、`px`、`py`（實際為 `var_b_raw`、`var_px`、`var_py`）→ Script 貼 `tm-b-flow-v1.txt` → `var_px < 0` 不要去夾，否則用 `var_px`、`var_py` PTP。

## 當天操作

1. **手臂先離開鏡頭**  
2. 開 `python3 main_contest.py --no-ui`，等快照完成 + 階段二  
3. 跑 **b Script**（送 `GET`）  
4. `var_px ≥ 0` → 去夾再放置；`var_px < 0`（`$B,-1,-1`）→ 沒目標，不要動  
5. 下一件再跑一次 b Script（又一次 `GET`）  

**口訣：** 先校正顏色＋仿射＋`PICK_ORDER` → 開機手臂離鏡 → 要座標跑 b → 看 `var_px`／`var_py`（負數別夾）。

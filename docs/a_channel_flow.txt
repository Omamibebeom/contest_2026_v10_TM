// a / b 通道說明 (本檔是說明書, 不是可貼上的 Script)
//
// ★ 可貼進 TMflow 的檔案:
//      a 讀顏色: docs/tm-a-flow-v1.txt   → $A,<code>
//      b 要座標: docs/tm-b-flow-v1.txt     → $B,<x>,<y> 或 $B,NONE
//
//==============================================================================
//
// 網路
//   樹莓派 192.168.1.10:5000 (Server)
//   手臂   192.168.1.20     (Client)
//
// 讀顏色流程
//   1. 圖元: 夾取 → 移到鏡頭前檢測位
//   2. Script: 貼上 tm-a-flow-v1.txt
//   3. 圖元: 依 color_code 分支放到對應區 → 開夾爪
//
// 句子
//   手臂送 A_REQ  → 樹莓派投票約 3 秒 + 再等 1 秒 → 回 $A,<code>
//   手臂送 A_DONE → 才能做下一件 a
//
// code 表 (預設 IO_CODES)
//   1 red / 2 blue / 3 green / 7 失敗
//
// 樹莓派端
//   python3 main_contest.py --no-ui
//   看到「階段二」再按手臂
//
// 注意
//   - 不要用 tm-b-flow-v1.txt 來讀顏色 (那是 GET 座標)
//   - 全場 socket_open 一次即可; a/b 共用同一條連線
//   - 每件 a 讀完一定要 A_DONE
